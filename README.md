
## 🔍 Quick Overview

### NumPy (`01_Numpy/`)
- **Arrays**: Create and manipulate n-dimensional arrays
- **Indexing & Slicing**: Access and filter array elements
- **Operations**: Mathematical operations, sorting, and concatenation
- **Real-world**: Sales analysis, vector operations, visualization

### Pandas (`02_Pandas/`)
- **Series & DataFrames**: Work with structured data
- **Data Cleaning**: Handle missing values with `dropna()` and `fillna()`
- **Merging & Joining**: Combine datasets intelligently
- **GroupBy & Aggregation**: Summarize and analyze grouped data
- **Pivot Tables**: Reshape data for insights
- **Real-world**: Anime dataset analysis with data transformation

- Series and DataFrame creation
- Handling missing data
